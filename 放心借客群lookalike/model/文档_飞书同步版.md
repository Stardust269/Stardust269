# 放心借 lookalike 建模（LightGBM + PU）

在**马消存量背景人群**（未标注, U）中，学习**低定价放心借种子用户**（正类, P）的共性，输出 lookalike 评分用于扩量营销。

---

## 业务定义

**P（pu_label=1）**
- 利率 < 18%
- 且**借款当日**有征信报告（`days_dt_zx = lend_date_sj`）

**U（pu_label=0）**
- 宽表中其余用户（背景约千万级；含隐藏正例）

**特征来源**
- Hive 宽表：`fxj_ayh_seed_users_expansion_tx_cpd_fpd_bh_rzdz_pd_multiloans_feature_with_credit`
- 含：放心借 D 变量 + 腾讯/百行/朴道 + 征信 `latest_*` / `zx_*`
- **不入模**种子规则字段（如 `y_loan_base_rate`、`lend_date_sj`），避免标签泄漏

**业务背景文档**：仓库 `../notion/放心借lookalike.md`

- `predict.py` 默认读 `--config` 做 parquet 列裁剪
- 分块打分走 numpy 矩阵
- `max_bin: 127`、`num_threads: 2`

## 4. PU 方法（`config.yaml` → `pu.method`）

**elkanoto（默认）**
- `pulearn.ElkanotoPuClassifier` + `LGBMClassifier`
- 从未标注集中 hold-out 估计类先验

**weighted_naive**
- 原生 LightGBM，`sample_weight`：P=1，U=`unlabeled_weight`（弱负例近似）

未标注量极大时，训练集对 U 做 `unlabeled_subsample_ratio` 下采样（验证集仍全量）。

---

## 5. 指标解读

验证集打印 `auc_p_vs_u`、`precision_at_1pct` 等：将 U 临时当作负例，**仅作训练监控**，不代表真实泛化 AUC。

更关注：
- `score_gap_pos_minus_unl`
- Top 分位中正类占比

## 7. 决策树探查与可视化

### 7.1 这是干什么的？

在 LightGBM 全量模型训练完成后，用 **Top N 重要特征**（默认 Top10）再训一棵**很浅的决策树**（默认 `max_depth=4`），用来回答：

- 是否**少数几条规则**就能把种子和背景几乎分开？
- 若是，要警惕**强特征或标签泄漏**（规则是否等价于种子定义本身）。

这不是上线用的预测模型，而是**可解释性探查工具**，给同事看「几条 if-else 能分多准」。

### 7.2 涉及脚本

- `scripts/decision_tree_probe.py` — 训练浅层树、打 train/val/test 指标、写出 joblib/树图/规则文本
- `scripts/plot_decision_tree.py` — 从已有 `dt_probe_*.joblib` 单独导出 PNG/DOT/节点 CSV
- `src/tree_viz.py` — 节点种子数、seed%、seed recall 标注与出图逻辑

### 7.3 前置条件

- 已有 LightGBM 模型：`artifacts/lgbm_fxj_lookalike_pu_train_window_*.txt`
- 已有特征重要度：`artifacts/lgbm_fxj_lookalike_pu_train_window_*_feature_importance.csv`
- 训练数据：`data/training_pu_train_window.parquet`；时间外评估需 `data/test_window.parquet`
- **出图依赖 graphviz**（pip 的 graphviz 包不够，需系统二进制）：
  ```
  conda install -c conda-forge graphviz
  ```

### 7.4 命令：train 拟合 + val 评估 + 导出树图

# 基于 test 样本重算每个节点的种子数/占比/召回，再出图

### 7.8 典型产出（artifacts/dt_probe/）

**dt_probe_top10_<时间戳>.joblib**
- 浅层决策树 + Top 特征名 + train 节点统计（可复用评估/出图）

**dt_probe_top10_<时间戳>_tree.png**
- 树结构图；节点框标注：`seeds`（种子数）、`seed% in node`、`seed recall`（该节点召回全量种子的比例）

**dt_probe_top10_<时间戳>_tree.csv**
- 每个节点的样本数、种子数等明细

**dt_probe_top10_<时间戳>_tree.dot**
- Graphviz 源文件，可手动改样式后 `dot -Tpng ...`

**dt_probe_top10_<时间戳>.json / .txt / _report.md**
- 规则文本、train/val 指标、叶节点纯度摘要

**若加了 --plot-test**
- 还会生成 `*_tree_test.png` 等 test 版图与 CSV

### 7.9 怎么读结果

- **train AUC 极高、叶节点纯度 ≥99%**：可能「几条规则硬分开」，要查 Top 特征是否含泄漏字段
- **train 很高、test 明显掉**：过拟合或时间漂移，浅层规则不能时间外复用
- **Pred=SEED 叶节点 seed recall**：预测为种子的叶子里，召回了多少比例的全量种子

### 9.6 常用参数

**--config**
- YAML 配置路径；决定数据路径、白名单、PU 方法、TGI 分档口径

**--data / --train-data / --test-data**
- 覆盖 config 中的 parquet 路径

**--chunk-size 30000（或 20000）**
- 分块打分/评估行数；OOM 时调小

**--test-only**
- `report_eval` 跳过 train/val，仅评 test

**--top-k**
- `predict` 仅输出分数最高的 K 行

**--from-scores**
- `batch_predict_merge` 从已有 scores_all.parquet 重算分布

**decision_tree_probe 常用参数**
- `--top 10`：取 LightGBM gain Top10 特征入树
- `--max-depth 4`：树深度（越小规则越少）
- `--min-samples-leaf 200`：叶节点最小样本数
- `--test-data`：时间外 test parquet
- `--plot-test`：test 评估时额外导出 test 树图
- `--artifact`：已有 dt_probe joblib，跳过训练
- `--no-plot`：不导出 PNG

**plot_decision_tree 常用参数**

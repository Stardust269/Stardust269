# 放心借 lookalike：样本表补征信特征

## 背景

| 表 | 说明 |
| --- | --- |
| `lj_iceberg.ai_decision_dev.fxj_ayh_seed_users_expansion_tx_cpd_fpd_bh_rzdz_pd_multiloans_feature` | 扩量样本宽表（已含放心借 / 腾讯 / 百行 / 朴道等），**缺征信** |
| `..._feature_with_credit` | 本脚本产出：在样本表基础上挂**最近一次报告**的征信特征 |

同事约定（摘要）：

- `days_dt_zx`、`dt_zx`：样本侧**最近一次征信报告**时间，脚本不再 `row_number` 选报告。
- **不增加马消（安逸花）特征**。
- **借贷账户**：`loan_account_basic_info` 中**全部 `account_type`** 进入明细；宽表按 D1/R1/…/C2 拆列，未列入枚举的归入 `zx_OTH_*`（长表 `fxj_seed_credit_report_agg_by_type` 保留完整类型）。
- **0 / null**：`0` = 有报告、从已知数据可判断「没有/为零」；`null` = 无法从已知数据得出（如无正余额账户时的 `bal_max` / `util_*`）。有报告（`zx_has_report_flg=1`）时，**sum/count 类账户指标**在终表对缺失 join 做 `coalesce(..., 0)`。
- **特征金额盖帽**（建模用，非人行真值）：`|金额| > 9_999_999`（整数部分超过 7 位）→ **1_000_000** 元；适用于征信脚本产出的余额/授信/逾期金额等；计数、比例、flag 不盖帽。
- 余额/额度汇总仍**剔马消**机构码 `T10156530H0001`（与 jcr Part 3~4 一致）。`latest_*` 合计为**全账户类型**合计，不再仅限 R1–R3。

## 运行顺序

1. 确认样本表 `unique_id` ↔ 征信 `id_unqp`，`dt_zx` 为 `yyyyMMdd`。
2. 按段执行脚本 Part 1 → Part 6。**Part 2 若 exit 137 且不能调 executor**：先 `bash scripts/run_part2_account_batches.sh`（默认 64 批），再跑 Part 3～6；或只跑 `sql/fxj_seed_credit_account_part2_light.sql`。
3. 核验关注：
   - `has_zx_report_cnt`：`summary` 能挂上 `id_unqf` 的人数（应接近 `has_dt_zx_cnt`）。
   - `has_bal_sum_known_cnt`：有报告且 `latest_bal_sum` 非 null（改版后应等于 `has_zx_report_cnt`）。
   - `bal_sum_zero_cnt`：有报告但全类型余额合计为 0（含原「无循环贷明细」人群）。
   - `dt_zx_but_no_summary_cnt`：样本有 `dt_zx` 但 summary 无报告（应极少）。

## 终表字段提示

| 字段 | 含义 |
| --- | --- |
| `zx_has_report_flg` | summary 是否挂上 |
| `latest_*`（`latest_bal_sum` 等） | 全类型借贷账户合计（剔马消后余额/额度类），金额 `decimal(18,2)` |
| `latest_credit_amount` / `latest_credit_used_amount` | 人行 `credit_loan_summary` 贷记卡账户汇总额度/已用（元），`decimal(18,2)` |
| `latest_credit_util_rate` | 已用÷授信；`decimal(18,6)` |
| `latest_util_*` | 余额/授信比；`decimal(18,6)`，特征侧 `least(比值, 9999.999999)` 封顶（非人行真值，避免极小授信导致百万级比值） |
| `zx_{D1,R1,…,OTH}_*` | 分账户类型；每类含 `acct_cnt`、`pos_bal_acct_cnt`、`bal_sum`、`crdt_sum`、`bal_max` 等 |

若 `group by account_type` 出现新枚举，先查脚本末尾诊断 SQL，再在 `fxj_seed_credit_report_agg_pivot` 中补列或调整 `OTH` 白名单。

## 与 jcr 项目

- `jcr_credit_*_20260715` 仅 jcr cohort；放心借须单独跑 `fxj_seed_*`。
- jcr 的 `latest_*` 来自多报告窗口 + 仅 R1–R3；本脚本为**单报告 + 全类型**，数值不必与 jcr 逐列相等。
